Project Description 
The Smart Student Portal is a multi-page educational website developed entirely using HTML5.
It provides information about courses, faculty, admissions, timetable, library ,events, gallery, and student services. 
It demonstrates semantic HTML5, hyperlinks ,tables, forms, lists, images, audio, video, and iframes.
All pages are connected through a navigation menu and resources are organized into separate folders.

Technology Stack
• HTML5
• Semantic HTML Elements
• Hyperlinks
• Tables
• Forms
• Lists
• Images
• Audio
• Video
• iframe (Google Maps and YouTube)
Note: HTML only; no CSS or JavaScript.

Features
• Multi-page website
• Home, About, Courses, Faculty, Admissions
• Student Dashboard
• Timetable
• Library
• Gallery
• Events
• Contact Page with Google Maps
• Login, Registration, Admission & Feedback Forms
• PDF resources
• Audio & Video integration
• Internal & External Hyperlinks

Steps to Run the Project
1. Download or extract the project folder.
2. Open it in Visual Studio Code or any HTML editor.
3. Verify that pages, forms, images, media, and documents folders exist.
4. Open index.html.
5. Run using Live Server or open in a browser.
6. Navigate through all pages.
7. Verify forms, images, audio, video, and PDF links.
